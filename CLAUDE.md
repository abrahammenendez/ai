# ai

My Claude Code and Codex setup: settings, my own skills, and the third-party skills `setup.sh` installs. README.md has the rest.

## Commands

<!-- Exact commands, narrowest first (one test, one module). Add each the first time it's needed. -->

- `npx -y skills@latest add . --list`: lists the skills `setup.sh` will install from this repo. A skill missing here has a broken SKILL.md.
- `bash -n setup.sh`: syntax check.
- `skills/gitignore/scripts/fetch-templates.sh --list`: checks that the github/gitignore fetch still works.

## Rules

<!-- Facts the code doesn't show. Add one when an agent gets something wrong:

- The repo is public. Keep out personal details, secrets and machine-specific paths; my personal instructions live in the dotfiles repo.
- Name no model versions, tool versions or counts: they go stale. Use aliases such as `opus`, and link to the source instead.
- Link to third-party skills; never copy them here. Skills for a specific technology go in CATALOG.md, and changing it means updating its "Last reviewed" date.
- Every folder in `skills/` is installed in every project by `setup.sh`, so a skill belongs there only if it's useful everywhere. Each follows the Agent Skills specification (agentskills.io/specification): the folder name matches `name`, and SKILL.md stays under 500 lines.
- Check a changed skill against its cases in `evals/`, running each case with and without the skill (Anthropic's skill-creator does this).
- README.md's skill tables list what `skills/` and `matt_skills` in `setup.sh` install; change them together.
